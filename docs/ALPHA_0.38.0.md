# Alpha 0.38.0 — Core Systems Visual Rebuild

This release visually rebuilds Laboratory, Research, Structures, Quests, Campaign and Achievements.

## Highlights
- Screen-specific cinematic backgrounds with mobile variants.
- Unified glass panels, hero sections, stats and card language.
- Improved locked/completed/available states.
- Sticky quest navigation on small screens.
- Responsive campaign, laboratory and research layouts.
- Legacy achievements restyled as a collection wall.
- No gameplay balance or save-data schema changes.
