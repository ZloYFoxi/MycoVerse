# Patch Notes

## Alpha 0.7.0 — Miner Integration

### New
- Locked miners can now be awakened with Spores.
- Miner collection progress appears in the Miners tab.
- Every miner resource is integrated into the legacy production pipeline.

### Compatibility
- Internal resource ID `wood` remains the Spores resource for save compatibility.
- Existing Alpha 0.6 miner saves load automatically.

### Test checklist
1. Start a new game and confirm Spore Worker produces Spores.
2. Open Miners and evolve Spore Worker.
3. Accumulate 250 Spores and awaken Glow Forager.
4. Save, reload, and confirm miner ownership and levels remain.
5. Confirm offline gains include miner production.
